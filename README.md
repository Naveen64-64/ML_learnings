# ML_learnings


1. Linear Regression
It predicts a continuous number using a straight-line relationship.

Example:
Study hours → Exam score

If a student studies 5 hours, the model might predict 65 marks.

Output: a number like 65, 72.5, 89, etc.


2. Logistic Regression
It predicts which category/class something belongs to, usually using probability.

Example:
Study hours → Pass or Fail

The model might say:

80% chance of Pass

Output: probability/class like Pass or Fail.



3. Polynomial Regression
It is used when the relationship between the input and output is curved instead of straight.

Example:
Study hours → Exam score

Initially, studying more may increase marks quickly, but after many hours, the improvement may slow down.

Polynomial regression can fit this curve better than a straight line.

Easy way to remember
Linear → Straight line → Number
Logistic → Probability → Class
Polynomial → Curve → Number
